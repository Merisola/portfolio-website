# The Alchemist Portfolio: Transforming Code into Clarity

A dual-persona portfolio built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion**. This project showcases the intersection of technical Full-stack development and strategic Project Management.

## 🛠 Tech Stack
- **Frontend:** Next.js (App Router), TypeScript
- **Styling:** Tailwind CSS (Custom Design System)
- **Animations:** Framer Motion
- **Architecture:** Modular Component-based structure

## 🚀 Branching Strategy
- `main`: Production-ready code.
- `staging`: Pre-production testing environment.
- `dev`: Active development and feature integration.

## 📈 Financial Intelligence & PM Principles
This project is built using:
- **Risk Management:** Strict branching and type-safety.
- **ROI Focus:** Automated workflows and optimized build times.
- **Agile Methodology:** Broken into 20 distinct milestones.
